ABOUT
-----

Dark Fantasy UI – Free Sampler is a free selection of 5 handcrafted UI sound effects taken from Dark Fantasy UI – Vol. 01, a 35-SFX library designed for dark-fantasy games.

The sampler includes one representative sound from each of the five functional categories in the full pack: Navigation, Feedback, Inventory, Rewards and Magic.

It is intended for RPGs, dungeon crawlers, adventure games, horror games and other projects that need a dark, arcane interface sound identity.


CONTENTS
--------

5 unique UI sound effects:

Navigation — UI_Hover_01.wav
Feedback   — UI_Confirm_01.wav
Inventory  — UI_Item_Equip_01.wav
